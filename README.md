# Retail Sales Dashboard

## Project Overview
An interactive Retail Sales Analytics Dashboard created to analyze sales performance, profit contribution, regional trends, and sales channels using spreadsheet-based data analysis and visualization.

## Objectives
- Analyze total sales and profit.
- Compare sales performance across different regions.
- Understand category-wise sales contribution.
- Track monthly sales trends.
- Build an interactive dashboard using filters and charts.

## Tools & Technologies
- Microsoft Excel
- Google Sheets
- Pivot Tables
- Pivot Charts
- Slicers / Filters
- KPIs
- Data Visualization

## Dataset
The project uses a retail sales dataset containing information about:
- Order ID and Order Date
- Region and City
- Product Category and Product
- Sales Channel
- Customer Segment
- Quantity and Unit Price
- Discount, Sales and Profit
- Payment Method

## Dashboard Features
1. **Sales Performance:** Displays overall sales and profit insights.
2. **Regional Analysis:** Compares sales across Central, East, North, South and West regions.
3. **Category Analysis:** Shows sales and profit contribution by product category.
4. **Sales Channel Analysis:** Compares Marketplace, Online and Retail Store performance.
5. **Monthly Sales Trend:** Tracks sales performance throughout the year.
6. **Interactive Filters:** Allows users to explore data by region and category.

## Worksheets
- `Sales_Data` – Original retail sales dataset.
- `Pivot Table 1` – Pivot table analysis.
- `KPI_Guide` – KPI reference.
- `Data_Story_Template` – Data storytelling.
- `Dashboard` – Visual dashboard and charts.

## Key Learnings
- Data cleaning and analysis.
- Creating Pivot Tables and Pivot Charts.
- Calculating and interpreting KPIs.
- Building interactive dashboards.
- Presenting business insights through data visualization.

## Project Outcome
Successfully developed a retail sales dashboard to explore sales trends, compare regional performance, and understand category-wise and channel-wise business performance.
